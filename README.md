# 有道词典划词搜索 (Edge 增强版 v1.1)

适配 Microsoft Edge 及 Chromium 内核浏览器的划词搜索插件。结合了**就地释义浮窗**、**右键菜单**与**内置本地 PDF 翻译阅读器**。

---

## v1.1 升级特性

1. **就地释义浮窗（替代跳新网页）**：
   - 划选单词后点击红色“有道”按钮，**直接在网页旁弹出精致的释义卡片**，无需跳转新标签页打断阅读。
   - 浮窗内展示：**英/美音标、发音朗读按钮（🔊 点击直接发音）、详细词性与中文释义**。
   - 卡片支持**拖拽移动**（拖拽顶部即可挪动位置，防止遮挡原文），按 `Esc` 或点击空白处关闭。
   - 底部保留“在有道词典中查看更多 ↗”外链，随时可查看完整网络例句。
2. **内置本地 PDF 翻译阅读器（破除 Edge PDF 原生限制）**：
   - 内置基于 PDF.js 的本地极速阅读器，**将任何英语文献/六级 PDF 拖入即可阅读**。
   - 全面支持在 PDF 上自由鼠标划词，即刻享用有道浮窗查词与发音。
   - 100% 本地渲染，无需联网上传文件，隐私安全。
3. **防遮挡定位与个性化配置**：
   - 默认弹出在选区下方，完美避开 Edge 自带的黑色微型菜单。
   - 可在插件面板中自由切换“浮窗显示释义”或“打开有道网页”。

---

## Edge 加载与使用方法

1. 在 Edge 地址栏输入 `edge://extensions/` 并回车。
2. 找到 **“有道词典划词搜索”**，点击卡片右下角的 **🔄 刷新图标（重载扩展）**。
3. **体验就地释义浮窗**：
   - 打开任意普通网页（如维基百科、必应），划选任意单词（如 `Aposematism`）。
   - 点击出现的红色“有道”小按钮，即可就地看到弹出的音标、释义与发音按钮！
4. **体验本地 PDF 阅读器**：
   - 点击浏览器右上角插件图标，点击 **“📖 打开本地 PDF 翻译阅读器”**。
   - 将你的六级英语阅读 PDF 直接拖进页面中，选中单词即可畅享划词查释义！
